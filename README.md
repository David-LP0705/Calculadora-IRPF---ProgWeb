# 🧮 Calculadora de IRPF — Programação Web

Aplicação web desenvolvida para a disciplina de **Programação Web**, com o objetivo de calcular o Imposto de Renda Pessoa Física (IRPF) com base no salário mensal informado.

---

## 📁 Funcionalidades

O projeto conta com uma interface simples e direta para simulação do cálculo tributário:

* **Cálculo de IRPF** — Determina a alíquota aplicável e o valor a ser pago com base no salário bruto mensal informado.
* **Tabela de Faixas** — Exibe visualmente as faixas salariais e alíquotas de referência (tabela mensal de janeiro/2024).
* **Ações Rápidas** — Permite calcular instantaneamente os valores ou limpar os campos de entrada com um único clique.

---

## 🛠️ Tecnologias e Ferramentas

* **HTML5:** Estrutura da interface da aplicação.
* **CSS3:** Estilização dos componentes, tabelas e layout.
* **JavaScript:** Lógica para leitura do salário, verificação de faixas e cálculo do imposto.
